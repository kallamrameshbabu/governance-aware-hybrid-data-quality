# Claim Boundaries

This repository accompanies a research study on governance-aware hybrid decision fusion for enterprise data quality management.

To avoid over-interpreting the results, the following boundaries should be noted.

## Supported Claims

The experiments support that:

- heterogeneous evidence can be integrated into deterministic governance policies;
- nested experiment-level validation provides leakage-resistant evaluation;
- Hybrid V3 significantly reduces false positives relative to Hybrid V1;
- AI consensus achieved the highest numerical macro-F1;
- Hybrid V3 achieved statistically comparable macro-F1 to AI consensus under the evaluated conditions.

## Claims Not Supported

The study does **not** claim:

- universal superiority over all anomaly detectors;
- superiority over modern deep-learning anomaly detection methods;
- implementation of the complete NIST SP 800-207 Zero Trust architecture;
- validation through production deployment or human-in-the-loop operational studies.

These topics are identified as future research directions.
